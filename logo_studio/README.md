# استوديو تشريح الشعار — Logo Studio

برنامج يطبّق على أي شعار الخطوات نفسها التي وصلنا بها إلى الحاء والخاء في شعار Women Tech:
تحويل الشعار إلى منحنيات، ثم تعليم الضربات بيد المصمم، ثم القياس عند علاماته، ثم توحيد الأرقام،
ثم اختبارها على ضربات الشعار نفسه، ثم بناء الحرف الغائب من الخط المرجعي بهذه الأرقام فقط.

## التشغيل

```bash
pip install -r logo_studio/requirements.txt
python -m logo_studio          # يفتح http://localhost:8765
```

تُحفظ المشاريع في `logo_studio/projects/`، أو في المجلد الذي يحدده المتغير `LOGO_STUDIO_PROJECTS`.

## الخطوات الثماني

| # | الخطوة | من يقرر | ماذا يحدث |
|---|---|---|---|
| ١ | الشعار والمنحنيات | البرنامج | الحافة في منتصف المسافة بين لون الخلفية ولون الحرف، والزوايا الحادة فقط حيث ينكسر المحيط، وأقل عدد من منحنيات بيزيه بخطأ لا يتجاوز 0.15 بكسل. يُعرض التطابق مع الصورة وبُعد المنحنى عن الحافة. |
| ٢ | الوحدة وخط القاعدة | المصمم | الوحدة التي تُكتب بها كل الأرقام (في Women Tech: ارتفاع الحرف اللاتيني الصغير). يُعرض حجم البكسل بالوحدة، وأي فرق أصغر منه ليس حقيقياً. |
| ٣ | تعليم الضربات | المصمم | خط قصير عبر الضربة في كل موضع، مع نوع المكان: وسط عرضي، طرف عرضي عند شعيرة أو ملتقى حرفين، طرف عرضي عند جذع، أعلى الرأس، أعلى عمودي، وسط عمودي، أسفل عمودي، وصلة. |
| ٤ | القياس والتوحيد | البرنامج، والمصمم يعدّل | العرض عند النقطة التي يعبر فيها خط المصمم منتصف الضربة، عمودياً على الضربة. ثم قراءة كل ضربة كاملة بين علاماتها، وتوحيد كل نوع مكان بالمتوسط، وكل الشعيرات برقم واحد. وتُختبر قاعدة «الأتخن عند أخفض نقطة». |
| ٥ | الاختبار | البرنامج | تُعاد كل ضربة قيست من الأرقام وحدها على مسارها، وتُقارن بالأصل. |
| ٦ | الخط المرجعي | المصمم | خط من عائلة الشعار نفسها. يعطي الشكل والحجم والمكان فقط. الحجم بمطابقة ارتفاع حرف موجود في الشعار. |
| ٧ | بناء الحرف | المصمم يقسّم، والبرنامج يرسم | كل ضربة مجموعة من خطوط المرجع المرقّمة، بنوعها وما يلتقي بطرفيها. الوصلات بالحروف المجاورة تُرسم ضربات مستقلة. السُّمك كله من الأرقام الموحّدة، والحافتان تُرسمان حول منتصف الضربة، والأطراف مقطوعة لا مدوّرة. ثم يُقاس الحرف بعد رسمه بالطريقة نفسها. |
| ٨ | التصدير | — | منحنيات الشعار، والشعار مع الحرف الجديد كمنحنيات بيزيه، وتقرير بكل الأرقام والقرارات. |

## الاختبار

```bash
pip install httpx pytest
python -m pytest logo_studio/tests -q
```

`tests/test_end_to_end.py` يعيد جلسة Women Tech كاملة عبر البرنامج، ويتحقق من أن الأرقام هي التي وصلنا إليها:
أتخن العرضي ≈ 0.46، والشعيرة ≈ 0.066، وطرف الجذع ≈ 0.19، وأعلى الرأس ≈ 0.28، والقاعدة صحيحة في 5 من 5.
ويتحقق أيضاً من أن الحاء المبنية تطابق الجدول.
