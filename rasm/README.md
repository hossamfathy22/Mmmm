# رسم — محرك الخط العربي

محرك يعمل داخل المتصفح على جهازك: يقيس شعاراً، ويأخذ منه الأشكال المفتاحية، ويركّب منها ١٨ هيكلاً، ثم الحروف كلها في مواضعها الأربعة، ويكتب ملف خط OpenType مبرمجاً يشكّله أي برنامج.

```
شعار ← قياس القلم والنسب ← ١٢ شكلاً مفتاحياً + ٤ قطع صغيرة ← ١٨ هيكلاً ← ١٦٤ شكلاً ← ملف ‎.otf‎ (init · medi · fina · rlig)
```

## التشغيل

- **على أي جهاز:** افتح `rasm-standalone.html` في المتصفح. ملف واحد، ولا يحتاج خادماً ولا إنترنت (عدا خط الواجهة).
- **للتطوير:** افتح `index.html`، وهو يقرأ الملفات من `src/` مباشرة.
- **بعد أي تعديل:** `node tools/build.mjs` يعيد توليد `rasm-standalone.html`.

## المراحل كما في الواجهة

1. **الشعار:** PNG أو JPG أو SVG. يحدد المحرك السطر، ويقيس سماكة القلم والتباين وزاويته، والاستدارة، وشكل الأطراف، وارتفاع الألف والسن والنزول، والميل، وشكل النقطة وحجمها. كل قيمة قابلة للتعديل، والقيم المقاسة معلَّمة.
2. **الأشكال المفتاحية:** الساق، السن، الحوض، الكأس، الرأس، العروة، القوس، الأنف، رأس العين، الذيل، خط الكاف، الهاء، ومعها النقطة والهمزة والمدّة والوصلة. لكل خانة ثلاثة مصادر: من الشعار (آلياً أو بقصّ مستطيل منه)، أو مولّدة من القياسات، أو صورة ترفعها.
3. **الهياكل الثمانية عشر:** ا ٮ ح د ر س ص ط ع ڡ ٯ ك ل م ں ه و ى في مواضعها الأربعة، مع تلوين نصيب أي قطعة من كل حرف (الجزء المشترك وبقية الحرف).
4. **الخط الكامل:** الحروف بالنقاط والهمزات، ولام ألف، والأرقام والعلامات. تُتتبَّع الأشكال إلى منحنيات بيزييه، وتُكتب جداول GSUB، وأشكال العرض القديمة (U+FE70–FEFC) للبرامج التي لا تشكّل العربية.
5. **التجربة والتحميل:** كتابة حيّة بالخط الناتج، وصانع شعارات بالكشيدة (SVG/PNG)، وحفظ المشروع وفتحه (JSON).

## القرار الأهم: هيكل + قلم، لا قصّ صور

كل شكل مفتاحي محفوظ **خطاً مركزياً** (هيكلاً) يُرسم بقلم له سماكة وتباين وزاوية وأطراف. لهذا يمكن مدّ الحوض أو تقصير الساق دون أن تتغير سماكة الخط، وتلتقي القطع عند الوصل التقاءً نظيفاً. الصور المأخوذة من الشعار تُستعمل كما هي حيث يكون الشكل مستقلاً (النقطة، الساق مع طرفها، الرأس، العروة…)، أما ما يحتاج تمديداً أو وصلاً فيُولَّد من قياسات الشعار نفسه بقاعدة معلنة:

| الشكل | القاعدة |
|---|---|
| السن | الساق مقصوصة إلى ارتفاع السن |
| العروة | الرأس ممدوداً أفقياً |
| الهمزة | رأس العين مصغّراً |
| الدال | من خط الكاف |
| الياء | كأس ممدود |
| النقطتان والثلاث | نسخ النقطة |

## المعمار

| الملف | الدور |
|---|---|
| `src/core.js` | الهندسة (خطوط بزوايا مقوّسة)، «حمض» الأسلوب، المقاييس، القلم: أحادي السماكة أو عريض بتباين |
| `src/slots.js` | الأشكال المفتاحية والقطع الصغيرة: مولّد متجهي لكل شكل، واستبدال بصورة من الشعار أو مرفوعة |
| `src/recipes.js` | الوصفات: كل حرف في كل موضع قطعٌ بترتيب معلن، مع نقاط الربط وقواعد الوصل والعرض |
| `src/trace.js` | تتبّع الرسم إلى منحنيات: مربعات زاحفة بدقة دون البكسل، كشف الزوايا، ملاءمة شنايدر |
| `src/font.js` | كتابة ملف OTF عبر opentype.js، وجداول GSUB، والمشكِّل العربي، وتصدير SVG |
| `src/analyze.js` | قياس الشعار: العتبة، التحويل المسافي، الهيكل العظمي، السماكة حسب الاتجاه، السطر والارتفاعات، الأطراف، الاستدارة، النقاط والساق والعروات |
| `src/app.js` · `src/app.css` | الواجهة (مستوحاة من صفحات الخطوط في TypeTogether) |
| `tools/` | صفحات فحص للوصفات والخط والقياس، وسكربت البناء |

## ما تم التحقق منه

- الملف الناتج يجتاز OTS (المدقق الذي تستعمله المتصفحات) ويقرؤه fontTools بلا أخطاء.
- HarfBuzz يشكّل به: «بسم» ← ‎beh.init seen.medi meem.fina‎، «سلام» ← ‎seen.init lamAlef.fina meem‎، والكشيدة.
- القياس جُرّب على شعارات كوفية ونسخية ثقيلة: السماكة المقاسة قريبة من الحقيقية، والتباين يُكشف في النسخ، والنقاط الدائرية والمعيّنة تُعرف.

## الحدود الحالية

- اسم الخط بالحروف اللاتينية فقط.
- لا حركات (تشكيل) ولا أرقام لاتينية بعد.
- الاستخراج الآلي يأخذ النقطة والساق والرأس والعروة. بقية الأشكال تُقصّ يدوياً من الشعار أو تُولَّد.
- الأشكال المأخوذة صوراً لا تتمدد إلا الساق (يُحفظ طرفها ويُمدّ جذعها).
- الملف بصيغة CFF ‏(.otf). داخل صفحة Claude يُحفظ في ملف ZIP لأن الصفحة لا تسمح بحفظ ‎.otf‎ مباشرة.

## الخطوات التالية المقترحة

1. نقاط ربط قابلة للسحب لكل قطعة مأخوذة من الشعار (أين يدخل الوصل وأين يخرج).
2. تقسيم آلي للشعار إلى حروف حين يكتب المستخدم نص الشعار، فيُعرف كل جزء أي خانة يملأ.
3. وصفات بديلة لكل حرف (أسلوب نسخي، كوفي مربع، هندسي) يختار المحرك أقربها إلى الشعار.
4. الحركات، والأرقام اللاتينية، وجدول GPOS للنقاط والهمزات بدل دمجها في الشكل.
5. تصدير TTF وWOFF2، وخط متغير (محور الوزن) من قلمين.
