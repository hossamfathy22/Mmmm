# محرك خط (khatt)

ترفع صورة شعار وتكتب كلمة عربية، فيقوم المحرك بكل الخطوات:

1. **يقيس الشعار:** يحدد الأسطر، والشبكة (ارتفاع الحروف، والقاعدة، والصعود، والنزول)، والميل، وسمك الجذع، والخط الشعري، والتباين، والمسافة بين الجذوع، والنقاط، والشرطات، والفراغات المغلقة.
2. **يستنتج القواعد:** مثل «قلم واحد لكل الأسطر» أو «الأبيض بين الجذوع يساوي الجذع».
3. **يرسم كلمتك بنفس القواعد:** كل حرف عربي وفارسي بأشكاله الأربعة (أول، ووسط، وآخر، ومنفصل)، مبني من ست قطع: الجذع، وكأس الوصل، والرأس، والذيل، والنقطة، والشرطة.
4. **يُخرج النتائج:** صورة القياسات، والكلمة بصيغتي SVG وPNG، ومخطط البناء، وملف القواعد، وتقريرًا مكتوبًا.
5. **يشرح التصميم (اختياري):** يطلب من Claude شرح فكرة التصميم بالعربية.

## التثبيت

```bash
cd khatt_engine
pip install -r requirements.txt
```

## الواجهة

```bash
uvicorn server:app --port 8010
```

ثم افتح http://localhost:8010 وارفع الصورة واكتب الكلمة.

- **اختيار السطر:** إن كان في الشعار سطران (عربي وإنجليزي مثلًا)، اختر السطر الذي تؤخذ منه القواعد بزر «استعمل هذا السطر».
- **التعديل اليدوي:** من «عدّل القواعد يدويًا» تغيّر أي رقم (السمك، أو الميل، أو ارتفاع الحروف…) وتعيد التوليد دون رفع الصورة من جديد.

## سطر الأوامر

```bash
python -m khatt logo.png "بيدوناق" -o out/
python -m khatt logo.png "شركة القاهرة" -o out/ --line 2 --explain
```

## شرح Claude (اختياري)

يحتاج مفتاح Anthropic في متغير البيئة:

```bash
export ANTHROPIC_API_KEY=...
```

- **النموذج:** الافتراضي `claude-opus-5-5`، ويمكن تغييره بالمتغير `KHATT_MODEL`.
- **بديل تلقائي:** الطلب يفعّل خيار الخادم `fallbacks="default"`. إن رفض النموذج الطلب، يعيده الخادم تلقائيًا على نموذج بديل.
- **التكلفة:** كل شرح يُحتسب من حسابك في Anthropic. القياس والتوليد لا يحتاجان أي مفتاح.

## من الكود

```python
from khatt import run, Style, generate

r = run(open("logo.png", "rb").read(), "بيدوناق", out_dir="out")
print(r["style"])                      # القواعد المستخرجة

st = Style(stem=23, hair=4.5, x_height=66, slant=14)
open("word.svg", "w").write(generate("محمد", st)["svg"])
```

## الملفات

| الملف | الدور |
|---|---|
| `khatt/analyze.py` | قياس الصورة |
| `khatt/style.py` | القواعد التي تقود الرسم |
| `khatt/geometry.py` | القطع الأساسية: الجذع، والوصلة، والحلقة، والخط متغير السمك، والنقطة |
| `khatt/letters.py` | الحروف بأشكالها الأربعة |
| `khatt/typeset.py` | اختيار شكل كل حرف حسب اتصاله، وترتيب الحروف من اليمين |
| `khatt/render.py` | إخراج SVG وPNG ومخطط البناء |
| `khatt/explain.py` | شرح Claude |
| `khatt/pipeline.py` | يربط كل الخطوات |
| `server.py`, `static/index.html` | الواجهة |

## الاختبارات

```bash
python -m pytest -q tests
```

من بين الاختبارات اختبار ذهاب وعودة: يرسم المحرك كلمة بقواعد معروفة، ثم يقيسها، ويتأكد أن القياس يعيد نفس القواعد.

## حدود الإصدار الحالي

- **أسلوب الحروف:** الحروف بأسلوب هندسي واحد، تتغير أرقامه حسب الشعار: السمك، والميل، والارتفاعات، والإيقاع، والنقاط. المحرك لا ينسخ رسم حروف الشعار نفسه.
- **حروف مبسّطة:** بعض الحروف أبسط من غيرها، مثل ع وح وك في وسط الكلمة.
- **ما لا يُرسم بعد:** الحروف اللاتينية والأرقام والتشكيل. تُتجاهل، ويُذكر ذلك في النتيجة.
- **نوع الصورة:** أفضل النتائج مع شعار بلونين على خلفية سادة.
